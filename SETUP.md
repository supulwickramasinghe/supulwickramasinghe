# Setup

1. On GitHub, create a new **public** repository named exactly:

   `supulwickramasinghe`

2. Upload the contents of this folder to the root of that repository.

3. Your final structure should be:

```text
supulwickramasinghe/
├── README.md
├── assets/
│   ├── hero.svg
│   ├── projects/
│   │   ├── telecom.svg
│   │   ├── trading.svg
│   │   └── guest-shield.svg
│   └── badges/
│       ├── README.md
│       ├── fabric-analytics-engineer.png
│       ├── aws-cloud-essentials.png
│       ├── databricks-genai.png
│       ├── databricks-ai-agent.png
│       ├── databricks-fundamentals.png
│       ├── databricks-analytics.png
│       ├── aws-cloud-101.png
│       ├── ai-skills-fest-2026.png
│       └── databricks-sql-analytics.png
└── .github/
    └── workflows/
        └── snake.yml
```

4. Replace the placeholder badge PNGs in `assets/badges/` with your official badge images. Keep the same filenames.

5. Commit and push.

6. Open the repository's **Actions** tab and run **Generate contribution snake** once manually. After that it runs daily.

7. Visit `https://github.com/supulwickramasinghe`. GitHub automatically renders the profile README because the repository name matches your username.

## Optional edits

- Hero: edit `assets/hero.svg`
- Project cards: edit SVG files in `assets/projects/`
- Text/content/links: edit `README.md`
- Snake schedule: edit `.github/workflows/snake.yml`
